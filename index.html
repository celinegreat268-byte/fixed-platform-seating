User & access management

Admin dapat mengelola semua akun. Expat dapat membuat, mengubah, dan menonaktifkan akun Expat saja. TL tidak mengelola akun user.

Keamanan akun dijalankan melalui Supabase Edge Function manage-users. Secret/service_role key hanya disimpan sebagai secret server Supabase dan tidak pernah dimasukkan ke file HTML.

Daftar akun

NamaEmailRoleStatusAksi
Klik Refresh daftar untuk memuat akun.

Catatan keamanan: Expat dapat mengelola akun Expat saja. Hanya Admin yang dapat membuat atau mengubah role Admin dan TL. Semua tindakan pengelolaan akun diproses di server, bukan dengan service_role key di browser.
