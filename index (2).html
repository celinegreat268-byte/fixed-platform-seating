User & access

Setiap TL dan Expat dapat menggunakan akun sendiri. Hak akses dikendalikan berdasarkan role.

RoleAkses
AdminKelola user, employee database, platform, dan seluruh seating arrangement.
TLMelihat dashboard, mengisi dan mengubah nama serta platform pada kursi, mengelola employee database.
ExpatMelihat denah, dashboard, dan employee database (read-only).
Untuk membuat akun: Admin membuka Supabase → Authentication → Users → Add user. Setelah itu tambahkan profil user di tabel profiles dan pilih role admin, tl, atau expat. Petunjuk lengkap ada di README paket.
